# 交付、表格与持续返工

## 先判定返工性质

| 变动 | 执行范围 | 不做什么 |
|---|---|---|
| 评分、入题条件、分母、分组、方法或数据版本变化 | 修改既有配置/模块，重算依赖链，更新表图与解释；最终干净内核完整运行正式 Notebook | 不并排留新旧口径，不另建第二个正式 Notebook |
| 计算 bug 修正 | 定点修正，验证边界案例，按受影响依赖重跑，交付前完整运行 | 不借机换统计方案 |
| 用户明确只搬表、改格式、加图注/更新索引 | 使用指定现有结果的真实值，仅检查相关来源与目标；更新静态索引/日志 | 不重算，不从头检查全项目，不覆盖用户手改数据 |
| 图片视觉修改 | 复用已确认的图源汇总值，改绘图层，检查全部受影响图片 | 不改分母、分组和数值以配合视觉 |

“更新 Notebook”不等于伪造一次全量运行。纯排版任务可只改 Markdown 返工索引；独立索引显示单元若要刷新必须实际执行，不能手改 execution_count 或输出使其看似运行过。原统计输出保留真实生成时间。

## 稳定的工程接口

维护一个正式分析 Notebook 和既定结果工作簿。路径集中配置；重用读取、映射、衍生变量、统计、作图和表格函数。新增内容放到对应章节，不追加另一套完整管线。

建议维护分析台账：稳定 ID、研究问题、来源字段/版本、入题/有效掩码、分母、方法、状态、输出表/图编号。修改某个分母时追踪所有引用它的表、图、摘要和导出，不只修正一个可见数字。

用户重命名文件或手删列后，实际检查现有文件，不从旧代码重新导出覆盖。若新增表列所需数据已算过，优先取现有结果；未算过则先在原 Notebook 对应模块增加代码、运行后取值，绝不能凭语言模型补数字。

## 论文风格表格，不生成论文正文

可以交付可编辑 Word/Excel 表格与简短表注；不写引言、方法章节、讨论、结论或完整论文。用户给样式时优先遵守，没有样式再选择清晰可编辑形式。

分值分布表应保留：特征、类别、从最低到最高各分值 `n(%)`、调查人数、`M(Q1,Q3)`（若要求）、检验统计量、P。不要把分布列改成仅一列中位数；百分比标明行分母，组级统计量可合并单元格但数据结构保留组 ID。

搬运既有 Excel 表时定位真实标题/区域，照搬现有数值、表头、原选项顺序与注释。允许改展示表号但不能误把数值表的内部分析 ID 也改掉。仅用户要求“显著者”时筛选 Word 展示，完整 Excel 仍保留预定检验的全部结果，并注明展示为子集。

三线表参数可以配置，例如上下线 1.5 pt、中线/辅助线 0.75 pt；中文宋体、英文/数字 Times New Roman、中英文标题、7.5 pt 等都只是用户/期刊样式，不是强制通用默认。无要求时不强行小字号。处理重复表头、长表分页、宽表方向、注释间距，避免遮挡与截断。

有 documents/spreadsheets 技能时按当前环境入口使用；不要假定其私有路径。格式重要的 Word 应渲染核验新增/受影响页面，再检查既有内容未受损；缺渲染能力如实说明。复制表格数值与统计复算是不同验证层级。

## 图表

只生成研究问题要求的图，默认不补饼图、热图、散点图凑数量。中文标题/轴/图例、有效 n 和比例单位明确；选项保持逻辑顺序，图间方向和精度统一。

配置可用中文字体后实际检查渲染，不能只设置字体名就断言无乱码。保存指定格式（通常高分辨率 PNG，可按需 SVG/PDF），检查所有图中文字、刻度、图例、长标签和注释。固定图源数据与种子；保存文件路径和对应分析 ID。

需要美化时先询问是否使用 `lieflat-charts`，按 integrations 参考执行。不把既定 PNG 交付替换成只有 HTML；不把统计门控失败项绘成有“显著星号”的图。

## 文件安全与导出

- 先检查目标是否被占用/编辑、源和目标是否同一路径、工作簿是否有待保留的用户改动。遇并发修改停止当前保存，核对后再合并，不能让旧编辑器缓存覆盖新磁盘内容。
- 经用户授权修改既有成果时创建最小备份或用既有版本管理；临时文件在明确的临时目录内，验证后替换目标。不自动删除用户备份或另建“最终最终版”。
- Excel 工作表按研究主题组织，不大量新增无意义表。新增/修改日志表以项目规则为准；若禁止新增其他表，就不要添加验证表来规避。
- 普通结果表导出 `index=False`，但显式把有含义的索引转成字段。原工作簿保真编辑不能用整本 pandas 重导代替。
- 重新打开结果文件核对表名、关键字段、行列数、总数/有效 n、抽查或全量比对相关数值、暂停项无正式 P。检查 PNG 和要求的文档真实存在。
- 输入文件 hash 不变；保留数据不被再次删减。用户要求打开交付物才打开，不抢占整个桌面或关闭其应用。

## 日志与运行验证

最小返工记录：唯一 change_id、真实时间/时区、用户要求、影响模块、来源版本、修改前后口径、是否重算及范围、产物、验证结果、未解决项。一次返工一条主记录，重复运行不能反复追加同一记录。日志不是新的统计结果表。

首次正式分析或统计代码变化后，用确认的同一解释器启动干净内核，从首个单元顺序运行；清理与新代码不一致的旧输出。断言字段、评分范围、二元变量、有效 n、分组合计、结果导出回读和文件存在，不能只做语法检查。

如果用户明确要求“不重算/只排版”，执行上表的窄验证，日志写明复用既有统计结果；不要反过来用完整重跑规则扩大任务。

末尾索引给出完成模块、表/图位置、显著/不显著/暂停项（仅已做检验）、待决策问题及绝对路径。不要扩写论文正文。
