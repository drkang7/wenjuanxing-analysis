# 可选技能与 Gemini API 接入

核心分析不依赖外部文字服务或第三方美化技能。三项互相独立：启用 Gemini 不等于同意去 AI 味检测，启用美化也不允许改变统计方法。

## 首次询问与持久选择

第一次在当前用户/项目中使用本技能，且找不到适用的明确选择时，先问：

> 本技能可选接入 Gemini API，辅助撰写简短结果说明和图注，不生成论文正文。是否接入？可选“暂不接入（继续本地分析）”“使用已配置的 Gemini 接口”“需要指导接入”。外部调用可能收费，只发送你同意的脱敏汇总，不发送原始答卷或凭证。

未回复不等于同意。可以继续只读检查和不依赖该选项的本地任务，不能测试真实 API。即使系统有 `GEMINI_API_KEY`、ADC 或某技能默认调用授权，也必须确认本技能的选择。检查“是否已配置”也不能遍历/打印环境变量或读取凭证内容。

仅将选择写进项目本地非公开配置，例如 `.survey-local/options.json`：版本、已询问、`disabled/enabled/setup_requested`、允许用途、是否允许脱敏外发、确认时间、范围为本项目/用户明确的全局范围。不得写入 key、token、ADC 内容、项目凭证或原始答卷。配置不入公开包。跨项目不能无条件继承发送数据的许可。

选择需要指导接入，只表示可解释配置方法；不等于可创建云项目、启用结算、安装依赖或发起测试请求。用户确认接入方式、模型、费用边界和发送内容后再执行。撤回授权立即停止后续调用；不静默切换收费平台或模型。

## 1. Gemini 文字辅助（可选 `gemini-writer`）

允许用途：核实后结果的短摘要、图表说明、表注、字段解释、交付说明的简短改写。禁止扩展到论文正文；不让模型决定正确答案、评分、剔除规则、分母、统计方法或显著性。先完成统计再组织文字。

如果目标环境存在 `gemini-writer`：读取该环境实际的 `SKILL.md`，复用可用工具/适配器。**不要把作者本机版本的路径、默认授权、模型别名、云项目、赠金或账户设置复制到新项目。** 若其行为与本次明确许可冲突，以本次许可为边界，不执行超出部分。

没有该技能时可使用本包通用 `scripts/gemini_text.py`，需要用户环境已安装 `google-genai`。脚本不自动安装、不自动选择模型、不读 `.env` 或凭证文件、不打印凭证、不自动重试；真实请求需提供已确认的脱敏文字请求文件并加 `--send`。没有 `--send` 时只做本地请求校验，不读取密钥、不联网。这个适配器不是原 `gemini-writer` 的复制品。

接入支持两种互斥方式：

- Gemini Developer API：由用户在自己的进程环境/秘密管理器中配置 `GEMINI_API_KEY`；不要让用户把 key 粘到聊天、Notebook 或命令行历史。
- Google Cloud Vertex AI：由用户自己的 ADC 和环境设置提供项目/位置；不读取或导出凭证内容。不能沿用任何他人的项目 ID，也不能承诺赠金抵扣或零费用。

公开配置只包含占位字段与环境变量名称。模型 ID 由使用者确认当前可用值，不能把某人的 `quality` 私有别名当官方模型名称。需要配置指导时查当前官方资料，SDK 调用与当前环境版本不兼容就停止报告，不绕过错误改用未知接口。

通用适配器请求格式见 `assets/gemini_request.example.json`。`consent_confirmed` 和 `data_minimized_confirmed` 只能在用户真实同意、agent 完成人工核对后设为 true；不能为了通过脚本自己批准。发出前展示计划发送的事实范围/摘要，排除个人信息、逐卷明细和未获准材料。

返回后逐一核对 n、比例、P、ρ/统计量、分母、方向、暂停状态和限制。结果截断/安全阻断/空文本不能当完成。日志只记模型、时间、状态、用量等非敏感元数据，不记凭证；正文按用户要求保存。不得把本地自写内容冒称 Gemini 输出。

官方参考：[Google Gen AI Python SDK](https://googleapis.github.io/python-genai/)、[API key 安全与配置](https://ai.google.dev/gemini-api/docs/api-key)。公共包不含任何真实 API 接入配置；提供接口不是授权发起调用。

## 2. `lieflat-less-ai-tone`：去模板腔

用户提出减少 AI 味/让已有说明自然时，先询问是否采用该技能；点名或本任务已同意则不重复询问。它与 Gemini 可组合：先由获准的文字工具整理短说明，再检查表达，不重复改变事实。

使用目标环境实际安装的技能，完整读取其说明并遵循：先检测和语义审阅，交付具体的改前报告，**等用户确认修改建议后**再改写和复测。不把使用技能的同意误认为用户已经接受所有具体文字改动。

只处理获准的结果短说明/图注/表注，不改数值、方法名称、必要限定、引用或代码；不能承诺通过某种 AI 检测，也不伪造人类经历、故意加错或删除限制来“去 AI 味”。缺失该技能则说明未调用，可按用户选择走普通编辑。

上游：[lieflat-less-ai-tone](https://github.com/larashero3-dotcom/lieflat-less-ai-tone)。许可检查时为 CC BY-NC 4.0；安装/分发前以当前上游 LICENSE 为准。本包仅集成流程，不分发其代码、词库和模板。

## 3. `lieflat-charts`：图表美化

用户要求制作/美化数据图表时，先询问是否采用；用户已点名或本任务同意不重复询问。与去 AI 味需求同时出现可合并一次选项询问。纯计算、数据核验、Word 表格照搬不强迫启动图形技能。

启用后读取实际技能及其任务所需参考，使用其真实模板发现/候选流程，不凭印象自称用了模板。只输入已核对的汇总数据，记录对应 analysis_id、n、分母、单位和顺序。美化不能触发合并低频类别、改阈值、平滑真实比例或添加不成立的显著性标记；模板偏好与统计方案冲突时调整设计，不改数据。

原生 HTML/报告输出不能冒充 PNG、SVG 或可编辑 Office 图表。保留用户要求的最终格式；需要渲染转换时实际核验字形和数值。记录真实采用的来源/设计，不为“使用过技能”添加未经请求的水印。

上游：[lieflat-charts](https://github.com/larashero3-dotcom/lieflat-charts)。许可检查时为 PolyForm Noncommercial 1.0.0；以当前 LICENSE 为准。本包不复制画廊、第三方字体或模板，不把主包 MIT 许可延伸到这些资产。
