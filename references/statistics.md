# 正式统计：方案先于计算

## 方案与数据接口

读入指定清洗后文件，保留原数据副本且不删除答卷。先确认研究问题、自变量/结局变量、测量尺度、分组/评分、有效观测、统计方法、显著性水平及多重比较计划。缺方案时提出候选，不直接替用户批准。

可按研究主题设稳定模块 ID，例如 `[S2-0]` 环境字段、`[S2-1]` 样本、`[S2-2]` 主要主题、`[S2-OUTPUT]` 导出、`[S2-CHECK]` 验证；不能强行把不同问卷都改成营养标签章节。

前部配置集中保存路径、编码字典、题目正确答案、分组边界、分析清单、α、检验方向、卡方适用策略。衍生变量集中生成一次；下游复用，修改时清除失效旧结果。建议 `results[analysis_id] = {status, data, n, method, diagnostics, notes}`，状态区分 `ok`、`paused`、`not_requested`，展示表号独立于稳定 analysis_id。

## 有效 n 与题型

每张表/图保存并显示分母定义；同时保留符合入题条件人数、实际有效人数和排除于该项分析的人数/原因。仅某分析无效不等于整份问卷无效。

- 单选：保留原选项逻辑顺序和零频数选项；明确比例是总体比例、有效比例还是行百分比。
- 多选：分母是该题确认的实际作答人群，不是选项次数；每项独立计人数和选择率，比例和可超过 100%。部分漏答须按方案整题有效/逐项有效，不能暗中调整。
- 排序题：实际入题者分母；分别计算首位人数、进入前 K 人数。未入前列与没进该题是不同状态；校验名次重复/缺位，按设计允许范围处理。不要默认计算无意义的平均名次。
- 评分：正确答案由用户/可靠题目标准确认。精确多选评分要求选项集合完全等于正确集合，不能选中一项正确就给分。缺失、跳题和“不知道”由评分方案分别指定，不默认统统错误。分项二值和总分范围断言，保留原始分数。
- 等级/合计：不因都是 1～5 量表就相加成总分。合并职业、年龄等类别必须有批准的映射；所有获批共用此映射的分析引用同一个变量，原始值保留。
- 收入“不便回答”等非真实等级只在对应分析排除；不删除其他数据。IP 地区覆盖仅在用户要求时处理已有合法地区字段，不能默默把完整 IP 发给地理定位服务。

## 检验的可复用实现

同类方法只写一套函数：`frequency_table`、`multi_select_summary`、`row_percent_crosstab`、`run_chi_square`、`run_mannwhitney`、`run_kruskal`、`run_spearman`。现有可靠函数优先复用。标准库辅助模块仅负责部分确定性环节，正式统计使用项目环境中经过核实的库。

### 卡方前置门控

首先构建原始计数表，再算理论频数；独立观测等设计要求也须核实，配对/重复测量不能机械套独立性卡方。输出总格数、T<1/T<5 数量及比例、位置、有效 n 和是否满足策略。

下面是可供用户批准的**保守策略**，不是所有研究唯一合法的统计定律。`survey_core.chi_square_gate` 按此策略检查，不产生 P 值：

| 情形 | 动作 |
|---|---|
| R×C 非 2×2，所有 T≥1 且 T<5 格子≤20% | Pearson，`correction=False` |
| 2×2，N≥40 且所有 T≥5 | Pearson，`correction=False` |
| 2×2，N≥40，所有 T≥1 且至少一格 T<5 | Yates，`correction=True` |
| 2×2 的 N<40 或 T<1，或一般表未满足条件 | 暂停该项，不形成正式 P 值 |
| 空表、零边际、少于两组/两结果、无效计数 | 暂停并说明不可估计原因 |

零边际和稀少类别不能为了让函数成功而悄悄删去/合并。描述表保留原类别，推断表如何处理需有明确方案；已批准的处理须同时记录原表及实际分析表。

暂停项输出观察表、理论频数表、低频位置、为何近似不可靠、可选方向（保持描述/有理论依据重分组/经确认精确或模拟方法）。只暂停本项，不自动改用 Fisher、Monte Carlo 或调分组。Excel 写“未形成正式检验结果，等待人工决定”，P 留空而不是 0。

正式结果给出 χ²、df、P、n 和方法；如报告 Cramér's V，明确采用未校正 Pearson χ² 及其定义，不能随手把 Yates 统计量代进去。加权/复杂抽样不是普通计数卡方的自动适用场景。

### Mann–Whitney U / Kruskal–Wallis H

方案选用秩检验时：两独立组用 U；三组及以上用 H。输入个体原始得分/等级/计数，不用分布表频数替代个体观测，更不能把原始分数先分成三级再冒充同一个检验。

报告各组 n、M、Q1、Q3、U 或 H、H 的 df、P。U 默认双侧（除非批准单侧），明确组顺序及 exact/asymptotic、并列值处理。H 的 P 按其参考分布右尾计算，不把“双侧分析意图”实现成将 P 乘 2。小组样本量很小、常数结局或并列值等问题需报告，不擅自换方法。

结果是分布/秩的差异，不直接写“均值不同”；没有相应分布形状假设也不把 U/H 简化为单纯中位数检验。显著 H 只说明至少一组存在差异，不能指定是哪两组。

**不自动事后比较**。只有用户另外批准方法和比较族后才做，例如两两 U + Holm；记录整个预定比较族及原始/校正 P，不只对显著配对补校正。保留总体不显著结果和所有预定人群特征。

### Spearman

只计算明确提出的配对关系，使用成对有效个体数据；报告 n、ρ、P、方向及审慎的强弱描述，强度分界如使用应说明依据/约定。常数变量时不可估计；小样本近似 P 的局限需交代，若需置换等替代方法先确认。绘图 jitter 只改变显示，固定种子，不修改用于计算的数据。

### 数字呈现

按项目约定格式显示 P；常用 `P<0.001`，否则三位小数。保留机器数值用于计算，绝不显示 `P=0`。仅暂停时缺省 P；正常 P 的数值零也应格式化为 `<0.001`，不是缺失。

频数保留整数，百分比统一精度并说明分母；四舍五入可能导致合计 99.9%/100.1%，不要为了凑 100 改数。相关/差异不写成因果，未显著不等于证明“完全相同”。
