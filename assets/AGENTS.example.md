# 项目说明与 agent 协作规则（可选示例）

这份示例仅帮助整理项目要求，不是必填表，也不是已经确认的分析方案。可删减、调换顺序、改为普通自然语言，或完全使用自己的写法。未决定的地方写“待确认”，不要把空白或示例当成授权。

如需采用，可将适用内容放进项目的 `AGENTS.md`。已有该文件时请保留原有规则，只补充需要的内容；不要整份覆盖。也可以继续使用其他名称的项目说明，或直接在聊天中告诉 agent。

## 研究目标与本次范围

- 这份问卷希望回答什么问题：按需填写。
- 当前要做的阶段、完成后停在哪里：按需填写。
- 本次明确不做的事：按需填写。

## 输入文件与已有成果

- 本阶段允许使用的数据文件、当前版本：按需填写。
- 数据字典、问卷说明、正式分析方案的位置：按需填写；不清楚时让 agent 先核验。
- 继续维护的 Notebook、Excel、Word、图片目录：按需填写。

## 题目和编码说明

- 特殊题型、跳题条件、多选/排序分母：仅填写已知或已确认的内容。
- 特殊编码与缺失值含义：按题说明，不知道就写“待确认”。
- 如涉及评分，正确答案与评分方式：待确认后再计算，不凭题号猜测。

## 已确认规则与待确认事项

- 筛选规则、逻辑表达式和边界：按需填写，注明是否已经批准。
- 研究变量、分组、检验方法和显著性水平：按需填写，区分正式方案与候选方案。
- 遇到适用条件不足或不同文档冲突时，需要用户决定哪些问题：按需填写。

## 输出与协作偏好

- 输出格式、文件名、表图样式、语言与精度：按需填写。
- 需要保留的已有内容、运行环境限制、返工日志和重算范围：按需填写。
- 其他你希望 agent 遵守的注意事项：自由补充。

## 隐私与可选扩展

- 是否愿意了解/接入 Gemini API：可写“暂不接入”“需要指导”或自己的选择；是否允许某次发送数据还需明确范围。
- 是否希望使用去 AI 味或图表美化技能：按需填写，也可以等出现相应需求时再决定。
- 允许处理和外发哪些脱敏内容：按需说明。不要写入 API key、token、密码、凭证内容或可识别的答卷明细。

以上内容可以只保留与你的项目有关的几条，也可以全部重写。文件不是使用技能的前提，材料完整不等于获得额外删卷、扩展分析、上传数据或付费调用的权限。
